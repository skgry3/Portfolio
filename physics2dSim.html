Technical Highlights

Collision System

Detects and resolves overlaps between all shape pairs each frame, calculating penetration depth and push-apart vectors to keep shapes from passing through each other.

Separating Axis Theorem (SAT)

SAT works by projecting two shapes onto multiple axes and checking for overlap on each one. If any axis shows a gap, the shapes aren't colliding. If all axes overlap, a collision is confirmed and the shortest push-out vector is used to separate them. This makes it accurate for any convex polygon, not just circles or boxes.

Convex polygon support

Rather than hardcoding behaviour for specific shapes, the collision system works on any convex polygon by reading its vertices. This means triangles, squares, and pentagons all run through the same detection logic — making it easy to add new shapes in the future without rewriting the collision code.

Mixed shape collision pairs

The engine handles every possible pairing between the three shape types — Triangle↔Triangle, Square↔Square, Pentagon↔Pentagon, and all cross-type pairs. Each collision is detected and resolved correctly regardless of which two shapes meet, so the chaos on screen always behaves physically.

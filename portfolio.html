Technical Highlights

Responsive Layout

The site adapts across all screen sizes using CSS Grid and media queries. The sidebar collapses, columns stack, and spacing adjusts so the layout stays clean whether viewed on desktop, tablet, or mobile.

CSS Grid & Flexbox

The overall page structure is built with CSS Grid, defining named areas for the header, profile, main content, and sidebar. Flexbox handles alignment within individual components like the header tabs and contact links.

Multi-page Structure

The site is split across dedicated pages for Projects, Skills, and About Me, each sharing the same stylesheet and header so the experience stays consistent. Navigation is handled with plain anchor links and an active tab indicator set via JavaScript.

Custom Styling

All visual design is handwritten in CSS — no frameworks or templates. CSS variables define the colour palette and shadows site-wide, making it easy to retheme. Subtle gradients, hover transitions, and a grid overlay give the site a polished, cohesive feel.
